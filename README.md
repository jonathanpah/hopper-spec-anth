# hopper-spec-anth

[English](hopper-spec-anth-en/README.md) | [Português (Brasil)](hopper-spec-anth-pt-br/README.md)

A Claude Code skill that writes the spec for any deliverable. The skill fixes what every spec guarantees; the running model decides and records how to meet it, using the most current practice.

Uma skill do Claude Code que escreve a spec de qualquer entrega. A skill fixa o que toda spec garante, e o modelo em uso decide e registra como cumprir, pela prática mais atual.
