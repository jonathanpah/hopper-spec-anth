# hopper-spec-anth

[English](hopper-spec-anth-en/README.md) | [Português (Brasil)](hopper-spec-anth-pt-br/README.md)

A Claude Code skill that writes the 2 specs for a software product that AI agents build and prove with automated tests: the product spec, and the execution spec with the general body unchanged and the project annex.

Uma skill do Claude Code que escreve as 2 specs de um produto de software que agentes de IA constroem e provam com testes automáticos. A spec do produto e a spec de execução, com o corpo geral sem mudança e o anexo do projeto.

Choose one language and install its complete plugin. The 2 specs come out in the language of the installed plugin. The plugin and the skill are named `hopper-spec-anth` in both languages.

Escolha um idioma e instale o plugin completo dele. As 2 specs saem no idioma do plugin instalado. O plugin e a skill se chamam `hopper-spec-anth` nos 2 idiomas.

Each release includes both languages. The language folders separate documentation and packages; the installed name remains `hopper-spec-anth`.

Cada release inclui os 2 idiomas. As pastas por idioma separam documentação e pacotes, e o nome instalado continua `hopper-spec-anth`.
